# Client Init Guide

Use this guide after the base workflow has been installed into a client project.

## Goals

- understand the project structure
- suggest an initial root/module split
- explain how root and module work differ
- identify the first useful project-specific customizations

## Codex expectations

Codex should help the client by:
- inspecting the repository layout
- proposing initial module boundaries
- identifying likely root-owned work
- explaining the next recommended workflow action
- pointing out where project-owned customizations belong

## Important boundary

This guide helps configure the installed workflow for the project. It does not rewrite the managed base layer.
