# Stage Report Template

Use this template when a stage or substage stops.

Naming convention:

- `docs/plans/YYYY-MM-DD-stage-<id>-<topic>-report.md`

## Metadata

- Stage ID:
- Parent stage:
- Stage packet:
- Report date:

## Stage result

State one of:

- `passed`
- `blocked`
- `partial`

## Outputs produced

List the exact outputs created or updated by the stage.

## Gates passed

List every gate that passed, and note any gate that remained blocked.

## Unresolved items

List unresolved items that do not block understanding of the current state.

## Blockers encountered

List blockers encountered during execution. If none, say `none`.

## Assumptions used

List assumptions used during execution. If none, say `none`.

## Exact next recommended action

State the next concrete action in one short paragraph.

## Next stage eligible

State `yes` or `no`, and explain why.
