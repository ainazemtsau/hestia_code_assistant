# Hard Plan Review

Canonical documents in this subtree:

- `PLAN_CRITIC.md`
- `VERDICT_MODEL.md`
- `CRITIC_CHECKLIST.md`
- `STATE_TRANSITIONS.md`

These documents define the mandatory critic gate that applies after frozen planning and before later execution-facing stages. They establish the critic role, its read-only and adversarial posture, the verdict contract, the per-level critic checklist, and the state-transition semantics that later execution stages must inherit.
