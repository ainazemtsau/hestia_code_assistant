# Canonical Runtime

This subtree will hold the canonical runtime model for CSK vNext.

Stage ownership:
- `Stage 1` - entry, routing, root/module program model
- `Stage 2` - planning posture, artifacts, completeness sweep, and freeze rules
- `Stage 3` - hard plan review gate
- `Stage 4` - execution model
- `Stage 5` - review and READY
- `Stage 6` - retro and learning
